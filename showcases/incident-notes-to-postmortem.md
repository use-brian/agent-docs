# Turn incident notes into a blameless postmortem draft

> Approved for public scenario discovery. This prepared specification is not a verified incident analysis.

## Input

A synthetic incident timeline, impact summary, and engineering notes that do not prove a single root cause.

## Brian's job

Separate confirmed facts, impact, contributing evidence, unknowns, recovery, and follow-up proposals using blameless language.

## Expected result

A postmortem draft showing a 09:12–10:47 HKT impact window and explicitly stating that root cause remains unestablished.

## Evidence boundary

This does not establish root cause, recurrence prevention, or real customer impact.
