# Turn project updates into a delivery risk register

> Approved for public scenario discovery. This prepared specification is not a verified delivery result.

## Input

Three synthetic workstream updates containing milestone dates, dependencies, missing inputs, and blockers.

## Brian's job

Classify work as blocked, at risk, or on track; cite commitments and unknowns; and keep mitigations as proposals.

## Expected result

Atlas is blocked by missing API access, Juniper is at risk but not yet late, and Cedar remains on track.

## Evidence boundary

This does not establish project completion, mitigation effectiveness, or automatic status management.
