# Turn a recurring process into an approval-gated workflow spec

> Approved for public scenario discovery. This prepared specification is not an enabled or verified workflow.

## Input

A synthetic weekly process with input cutoff, report requirements, missing-input handling, and external-write approvals.

## Brian's job

Specify trigger, inputs, validation, state, exceptions, approval gates, idempotency, observability, and success checks without configuring anything.

## Expected result

An implementation-ready design where internal preparation may run automatically but reminders and distribution remain exact-action approved.

## Evidence boundary

This does not establish workflow execution, reliability, or autonomous external action.
