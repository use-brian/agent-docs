# Native application management

Local R5b implementation is in progress; it is not a deployment or qualification
receipt. Studio Mini apps manages registration and schema previews. Programmatic
access manages exact grants, named service identities and credential reviews.
Connectors shows source availability. People/access manages module roles and
configuration. Protected issuance and activation remain unavailable until R6.

The native-session routes are rooted at
`/api/applications/workspaces/:workspaceId/management`: GET reads a bounded
actor-bound metadata projection, POST `/commands` runs one typed canonical
management command, and POST `/mcp` exposes native Brian management tools.
Application OAuth and legacy API keys never acquire native governance.

`applicationManagementOverview` reads current admitted metadata.
`applicationManage` accepts a `command` discriminated by `kind`:
`register`, `status`, `grant.review`, `grant.apply`, `grant.revoke`,
`service.prepare`, `credential.review`, `credential.deliver`,
`credential.revoke`, `schema.preview`, `schema.apply`, `governance.catalog`,
`governance.preview`, and `governance.apply`.
Use the deployed input schema and governance catalog; never invent module,
role, resource, field or configuration operation names. Actor identity comes
from the authenticated native context and cannot be supplied by the model.

Preview a widening/schema/configuration/role change, show the exact saved review,
and apply only that confirmed review. Current actor, issuer ceiling and policy
are revalidated. A policy-changing operation can commit and then invalidate its
own invocation: `{error:"grant_revoked",effect:"committed",retrySafe:false}`.
Do not repeat the mutation. Start a fresh native invocation and read current
management metadata to reconcile the result. Network-uncertain effects also
require a read before taking further action.

Brian never receives plaintext credentials or private source keys. Credential
delivery returns a native human review link; only the human session can receive
one-time material. Never persist material in chat, logs or cached projections.
The prior credential cannot be replayed or regenerated by repeating delivery.

Unknown source mapping/retention/key capabilities are unavailable. Source trust
installation and key rotation require the deployment-owned path. Legacy repair,
qualified positive issuance, real provider QA and production activation remain
explicitly owed. Registration and a successful safe review do not certify them.

Native management denial (401/403/404) clears the human panel's protected view
before parsing even a malformed error body. It never retries the write. Re-enter
through current native authority and reconcile admitted metadata. The People/access
recovery destination uses `/organization?section=access`.

The bounded overview includes the selected module's governance catalog. Use the
optional `moduleKey` query parameter to select a deployed module; unavailable
module governance is explicit and is never an empty authorized role catalog.
The catalog has the same actor/workspace lifetime as the overview. After an
uncertain mutation, keep further writes disabled until a fresh authorized
overview succeeds. A failed reconciliation is not evidence to retry a write.
